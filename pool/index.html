A trading venue that lives entirely on chain

Every resting order is a real coin holding real escrow, governed by a covenant. There is no matching engine, no sequencer, no operator and no server. Anyone can read the book, verify every order independently, and take any of them without asking permission.

The market is Winiwa against USDx: test assets minted for this venue, backed by nothing and redeemable for nothing. Reading the book costs nothing and needs no balance.

Download

Reading the latest release from GitHub.

Desktop MiniDapp .mds.zip · ··· Android .apk · ···
  • Desktop. Install the .mds.zip in the MiniDapp store of the Minima node you already run. Trading needs write permission; reading the book does not.
  • Android. Install the APK beside Minima Core on the same phone. Signing an order needs the Admin toggle in Minima Core, and the app says so before it asks. Reading the venue never needs it.
  • Check what you downloaded. Every release publishes the SHA256 of each file in its notes. Compare it against the file before installing.

Source

The covenant scripts, the app and the design documents are one public repository. Every deployed address is listed in contracts/deployed/manifest.json, and tools/verify-contracts.mjs proves the shipped script text is byte for byte what is on chain.
